# Контрольні питання до лабораторних робіт

## Лабораторна робота №1
1. Що таке Node.js і для чого він використовується?
2. Яка роль фреймворку Express у розробці Node.js додатків?
3. Що таке REST API і назвіть основні HTTP-методи, які ви використали.
4. Яка різниця між методами PUT та PATCH?
5. Для чого потрібен `express.json()` (який ми підключаємо як middleware)?
6. Чим відрізняється Controller від Service у багатошаровій архітектурі? Навіщо взагалі розділяти код?
7. Що таке `package.json` і для чого потрібні залежності (`dependencies` та `devDependencies`)?
8. Які дані зберігаються в `req.body` та `req.params`?

## Лабораторна робота №2
1. Що таке ORM і які її основні переваги та недоліки порівняно з "чистими" SQL-запитами?
2. Як працюють ключові слова `async / await` у JavaScript і чому вони необхідні при роботі з базами даних?
3. Які змінні середовища та параметри зазвичай необхідні для підключення до PostgreSQL? Чому їх зберігають у файлі `.env`?
4. Що таке `next(error)` у фреймворку Express і як працює глобальний обробник помилок (Global Error Handler)?
5. Чому важливо валідувати вхідні дані на рівні бекенду (наприклад, за допомогою Joi чи Zod), якщо їх можна перевірити на фронтенді?
6. Що таке SQL-ін'єкція і як використання ORM допомагає від неї захиститись?

## Лабораторна робота №3
1. Які існують типи зв'язків між таблицями в реляційних базах даних? Наведіть приклади.
2. Що таке Foreign Key (зовнішній ключ) і яку роль він відіграє при побудові зв'язків?
3. Чому для ресурсу `Review` краще використовувати маршрут `/api/places/:placeId/reviews` замість `/api/reviews` у контексті створення відгуку?
4. Для чого потрібна опція `mergeParams: true` при ініціалізації Express Router? Що відбудеться, якщо її не використовувати у вкладеному роуті?
5. Що таке каскадне видалення (`ON DELETE CASCADE`) і як воно працює на рівні бази даних?
6. Які переваги та недоліки використання вкладених маршрутів у REST API?

## Лабораторна робота №4
1. Що таке аутентифікація та чим вона відрізняється від авторизації?
2. Як працює JWT (JSON Web Token) та з яких трьох частин він складається? Чи є дані в Payload зашифрованими?
3. Чому не можна зберігати паролі в базі даних у відкритому вигляді? Що таке "сіль" (salt) при хешуванні?
4. Як працює Auth Middleware в Express і як він отримує токен із запиту (наприклад, із заголовка `Authorization`)?
5. Як перевірити в контролері (чи сервісі), чи має право поточний користувач змінити або видалити конкретний ресурс (наприклад, місце)?
6. Як встановити термін дії (expiration) для JWT та що відбувається на сервері, коли токен протермінувався?
